# __NAME__

Website project created from the webdev-capabilities starter.

- `brief/` holds everything decided in the intake (start with `brief/BRIEF.md`).
- `PRODUCT.md` and `DESIGN.md` are the design context for the AI tools (written during the build).
- Run it: from the repository root, `npm run dev -- __SLUG__` and open the printed localhost address.
- Send it to someone: from the repository root, `npm run export -- __SLUG__` creates a single file in `exports/__SLUG__/`.

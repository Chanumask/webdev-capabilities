# examples/

Finished reference projects. They show the expected level of finish and hold code that capabilities are extracted from. They are not edited for clients; copy ideas into `capabilities/` or a site instead.

| Example | What it shows |
|---|---|
| `lindenhof` | Fictional property management company. Scroll-driven 3D construction story (finished house, rewind to the building site, vehicles and crane build it, neighbourhood), listings with filters, forms, restrained dark/stone design. Has a filled `brief/BRIEF.md`. |
| `lindenhof-v1-flat` | The first version of the same site: flat "Neues Frankfurt" colour-field look with floor-by-floor exploding house. Kept to show how the user's feedback changed the direction. |

Run any of them: `npm run dev -- lindenhof`.
